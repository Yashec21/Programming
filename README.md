# 🧠 Problem-Solving Approach

For each programming problem, I follow a structured approach:

``` text
Understand the Problem
        ↓
Identify Requirements
        ↓
Develop the Logic
        ↓
Choose the Appropriate Approach
        ↓
Implement the Solution
        ↓
Test with Different Inputs
        ↓
Handle Edge Cases
        ↓
Analyze Complexity
        ↓
Improve the Solution
```

### Key Principles

-   Understand before coding
-   Write clean and readable code
-   Use meaningful variable names
-   Test multiple inputs
-   Consider edge cases
-   Avoid unnecessary complexity
-   Improve solutions whenever possible

# ▶️ How to Run

## C Programs

Compile:

``` bash
gcc program.c -o program
```

Run on Linux/macOS:

``` bash
./program
```

Run on Windows:

``` bash
program.exe
```

------------------------------------------------------------------------

## C++ Programs

Compile:

``` bash
g++ program.cpp -o program
```

Run on Linux/macOS:

``` bash
./program
```

Run on Windows:

``` bash
program.exe
```

------------------------------------------------------------------------

## Java Programs

Compile:

``` bash
javac program.java
```

Run:

``` bash
java program
```

> Make sure the required compiler or Java JDK is installed and
> configured correctly in the system PATH.
